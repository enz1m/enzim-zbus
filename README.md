# enzim-zbus

An independently maintained enzUI fork of [zbus](https://github.com/z-galaxy/zbus).

Atomic close-on-exec reception of Linux file descriptors.

The canonical repository is [enz1m/enzim-zbus](https://github.com/enz1m/enzim-zbus).
Upstream crate names, history and license notices are retained.

```sh
git clone --branch enzim https://github.com/enz1m/enzim-zbus.git
cd enzim-zbus
```

See [FORK.md](FORK.md) for the base and patch list,
[VALIDATION.md](VALIDATION.md) for checks. The
[upstream README](README.upstream.md) is retained.
